# Password-Generator-with-Python's-Pyside6
This is a password generator made with python's GUI library. In this script, you have options to select what kind of password you want. This script is useful for creating strong passwords for login and stuff. It is made with python's pyside6 library. Pyside6 offers a very stylish and modern GUI feel in python scripts and applications. For this script to work on your computer, make sure you have python and its pyside6 library installed. For more, check out Requirements.txt and Steps_to_run.txt.
